## Architecture decisions

| Decision | Satisfied by |
|---|---|
| ADR-0001 — Contracts is a dependency-free shared kernel | Constants, Models |
| ADR-0002 — Registries and styles are pre-loaded once at startup | Pre-load |
| ADR-0003 — Generated XML is validated before writing | XML Validation |
| ADR-0004 — Manual layout is preserved across regenerations | Overlay |
| ADR-0005 — All layout modes share one BaseLayout/Result contract | Types & BaseLayout |
| ADR-0006 — Style identity is a normalized fingerprint | Normalize |
| ADR-0007 — Generation never calls notation at runtime | generate() |
